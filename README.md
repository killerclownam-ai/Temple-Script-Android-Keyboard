# Temple Script Keyboard — phone-friendly starter

This is an Android IME project for the Temple Script.

Build:
1. Open the folder in Android Studio.
2. Let Gradle sync.
3. Build > Build APK(s).
4. Install the debug APK on your Android phone.
5. Android Settings > Keyboard > On-screen keyboard > enable Temple Script Keyboard.
6. Select Temple Script Keyboard when typing.

IMPORTANT:
The project deliberately does not claim that the artwork is Unicode. The supplied Temple Script chart is the visual reference. The next production step is packaging the exact glyph artwork as a custom font/asset set and mapping every key to those glyphs.

Current keyboard: QWERTY, space, backspace, enter, and a numbers-layer button.
